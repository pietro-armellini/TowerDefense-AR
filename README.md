# Tower Defense AR
Tower Defense AR is an exciting open-source augmented reality (AR) game developed with Unity, allowing players to experience a tower defense game within their own domestic environment using their mobile phone camera.

# How to open the project
1. Clone the Repository: First, clone the Tower Defense AR repository to your local machine using Git: ``` git clone [https://github.com/your-username/tower-defense-ar.git](https://github.com/pietro-armellini/TowerDefense-AR.git)``` 

2. Open Unity Editor: Open Unity Hub and select Unity Editor version 2022.3 (or later).

3. Open the Project: In Unity Hub, click on the "Projects" tab and then click the "Add" button. Navigate to the directory where you cloned the Tower Defense AR repository and select it.

4. Configure Project Settings: Once the project is added to Unity Hub, click on it to open it in Unity Editor. Unity may prompt you to upgrade the project to the current version of Unity. Follow the prompts to upgrade if necessary.

5. Explore and Build: With the project open in Unity Editor, you can now explore the code, assets, and scenes. Build and run the game to experience Tower Defense AR in augmented reality!

# How To Play
1. Setup: Find a suitable area in your domestic environment with enough space to move around and place virtual towers.
2. Launch the Game: Open the Tower Defense AR app on your mobile device and grant necessary permissions for camera access.
3. Place Towers: Strategically place towers within your environment using the on-screen interface, taking advantage of terrain and obstacles to maximize their effectiveness.
4. Defend Your Territory: As waves of enemies approach, use your towers' abilities and upgrades to fend them off and prevent them from destroying the main tower.
5. Upgrade and Adapt: Earn currency by defeating enemies and use it to upgrade your towers to better defend against increasingly challenging waves.
